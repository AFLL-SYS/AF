## 四、面试题 40 题（答案要点版，每周刷一类）

### 网络
1. TCP 三次握手？（SYN → SYN+ACK → ACK；目的：确认双方收发都通）
2. HTTP 和 HTTPS 的区别？（端口 80/443；TLS 加密；证书）
3. 说 5 个常见端口？（22 SSH、80 HTTP、443 HTTPS、3306 MySQL、3389 RDP）
4. DNS 是干什么的？解析过程？（域名→IP；递归+迭代查询）
5. ARP 欺骗原理？（冒充网关回 ARP 应答，让流量经过攻击者）
6. 防火墙和 IDS/IPS 区别？（防火墙按规则拦；IDS 只告警；IPS 告警+拦）

### Web 安全
7. SQL 注入原理与防御？（输入被拼进 SQL；防御：参数化查询/预编译）
8. XSS 三种类型？（反射、存储、DOM；防御：输出编码、CSP）
9. CSRF 是什么？怎么防？（借用户身份发请求；防：token、SameSite）
10. SSRF 危害？（让服务器去访问内网：探测内网、读云元数据）
11. 文件上传怎么防？（校验类型+内容、重命名、隔离目录、最小权限）
12. OWASP Top10 说几个？（注入、失效认证、敏感数据泄露、XXE、失效访问控制……）
13. 加密和编码的区别？（编码可逆、无密钥，如 Base64；加密要密钥，如 AES/RSA）
14. 哈希特点？常用算法？（定长、不可逆、雪崩效应；MD5 已不安全、SHA-256）
15. 拿到 webshell 后先干什么？（确认权限 whoami、看网卡、找配置文件；别乱动系统）

### Linux
16. 查日志的命令？（tail -f /var/log/auth.log；journalctl -u ssh）
17. 怎么改文件权限？（chmod 644 file；r=4 w=2 x=1）
18. 查正在监听的端口？（ss -lntp 或 netstat -tlnp）
19. 找占用端口的进程？（lsof -i :80，或 ss -lntp 找 pid）
20. 计划任务怎么看？（crontab -l；/etc/cron*）
21. 怀疑被入侵先查哪几样？（当前用户、历史命令、开机启动、计划任务、异常进程、登录日志）

### 等保与工控
22. 等保 2.0 分几级？（1–5 级，五级最高；按受侵害客体+程度定级）
23. 等保测评流程？（定级→备案→建设整改→测评→监督检查）
24. 工业控制系统安全扩展要求多了什么？（室外设备防护、工业网络隔离、组态安全等，分技术+管理两大类）
25. IEC 62443 的 zones & conduits 是什么？（按风险划区域、区域之间用管道通信并做防护）
26. Modbus 协议有什么安全问题？（无认证、无加密、明文；知道地址就能读写寄存器）
27. PLC 有哪些攻击面？（工程软件、协议端口、HMI、U 盘、固件、供应链）
28. Stuxnet 一句话？（2010 年攻击伊朗离心机的蠕虫，针对西门子 S7，改转速并伪装正常读数）
29. IT 和 OT 安全关注点差别？（IT 机密性优先；OT 可用性和人身安全优先，不能随便停机打补丁）
30. 蜜罐是什么？Conpot 听过吗？（诱导攻击者的仿真系统；Conpot = 伪装西门子 PLC 的开源蜜罐）

### 行为与项目
31. 为什么机械专业想做安全？（诚实讲：工控安全需要懂 PLC 和现场的人，你正好两边都沾）
32. 说说你的项目？（按 STAR：背景→任务→动作→结果，提前练熟 5 分钟版）
33. 最近关注了什么漏洞/新闻？（准备 1 个，能说清影响面）
34. 能接受出差吗？（如实 + 说明范围；这行出差是常态）
35. 三年规划？（一年上手安服/测评 → 两年独立负责项目 → 三年往工控安全专）
36. 学历是专科，凭什么要你？（提前想好：动手能力 + 证书 + 项目 + 性价比，别支吾）
37. 你每天学多久？怎么学的？（讲你的打卡系统——这就是自律证据）
38. 简历里这个项目讲讲细节？（每个字都要能展开，没做的别写）
39. 有什么想问我的？（问：团队怎么分工、出差频率、新人培养方式——能问出这些说明做过功课）
40. 从零评估一家小工厂的工控安全，你会怎么做？（资产盘点→网络架构→授权扫描→访谈→报告；按这个框架说）
