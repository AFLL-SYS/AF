# 靶场清单（免费，按顺序打）

> 全部免费。原则：一次只打一个，打透再换；全部只在靶场/授权环境动手。

## 一、Web 靶场（本地起）

| 靶场 | 特点 | 什么时候打 |
|---|---|---|
| **DVWA** | 入门首选，四类漏洞+四档难度（你有） | 第 2 周 |
| **Pikachu** | 中文注释、新手最友好，GitHub 搜 zhuifengshaonianhanlu/pikachu | 第 2–4 周 |
| **sqli-labs** | SQL 注入 65 关，专练注入（Audi-1/sqli-labs） | 第 3–5 周 |
| **upload-labs** | 文件上传 21 关，专练上传绕过（c0ny1/upload-labs） | 第 4–5 周 |
| **bWAPP** | 100+ 漏洞，量大（有 docker：raesene/bwapp） | 第 5–8 周 |
| **WebGoat** | OWASP 官方教学版（Java），自带讲解 | 第 8 周后 |
| **XVWA / Mutillidae** | 老但全，社区经典 | 顺手 |

环境：DVWA / Pikachu / sqli-labs / upload-labs 都吃 PHP+MySQL——装一个 XAMPP 全搞定。

## 二、完整靶机（从外到内打整台机器）

| 平台 | 说明 | 入门顺序 |
|---|---|---|
| **VulnHub** | 免费下载 VM 镜像，导入 VMware 开机就打 | 先 **Kioptrix Level 1**，再 **DC-1** |
| **TryHackMe** | 在线、有引导、有免费房间 | Complete Beginner 房间线 |
| **HackTheBox** | 在线、真实感强、免费部分 | 先打 Starting Point |

**打完整靶机前置**：Kali 和靶机要在同一网段（VMware 里都用"仅主机模式"或都桥接），Kali 里 `nmap -sV 靶机IP` 找开放端口——这就是"侦察"的第一步。

## 三、工控 / OT 靶场（你的主赛道）

| 靶场 | 是什么 | 什么时候打 |
|---|---|---|
| **OpenPLC** | 跑在 PC 上的软件 PLC，支持 Modbus TCP | 路线第 3 周 |
| **pymodbus 从站** | 自己用 Python 写"假 PLC" | 第 3 周 |
| **ModbusPal** | Java 图形界面的 Modbus 从站模拟器 | 第 3 周（可选） |
| **Conpot** | 工控蜜罐，伪装西门子 PLC | 第 4 周 |
| **GRFICS v2** | VirtualBox 整套工控仿真（化工过程+PLC+网络） | 第 5–6 周，装不动就记方案 |

## 四、CTF 平台（练比赛，从 Web 分类开始）

| 平台 | 特点 |
|---|---|
| **BUUCTF**（buuoj.cn） | 中文、题量大、Web 分类适合入门 |
| **NSSCTF**（nssctf.cn） | 中文、新生友好、有题解氛围 |
| **CTFshow**（ctf.show） | 中文，按知识点成系列 |
| **攻防世界**（adworld.xctf.org.cn） | 老牌 |
| **picoCTF** | 英文但官方课程式引导，适合顺手练英语 |

**打法**：先做 Web 分类 → 卡 30 分钟就查 WriteUp → 看懂后**自己再复现一遍**，写进打卡。查题解不可耻，抄完不复现才可耻。

## 五、推荐顺序（和路线文件对齐）

1. 第 2 周：DVWA（手册在 [渗透实验手册_DVWA四类漏洞.md](12_渗透实验手册_DVWA四类漏洞.md)）
2. 第 3–5 周：sqli-labs 前 10 关 + upload-labs 前 5 关（配合 SQL 进阶手册）
3. 第 4 周：Conpot + OpenPLC（OT 主线）
4. 第 6 周：BUUCTF Web 分类刷 5 题
5. 第 7 周后：Kioptrix 完整靶机（你的第一台"整机战果"）

## 六、三条规矩

1. **只打清单里的东西**。互联网上任何真实系统都不在练习范围内。
2. 卡住先查官方文档/WriteUp，再问 AI，最后再问人。
3. 每打穿一个，打卡里记：用了什么思路、卡在哪、新学了一个什么点。
