# 秋招前 30 天冲刺清单（2027 年 8 月执行）

> 到 2027 年 8 月 10 日前后打开这个文件，按周执行。目标：9 月秋招开闸时你是第一个递简历的人。

## 第 1 周：家底盘一遍（8.10–8.16）

- [ ] 简历第三版：按 [求职包_简历模板_面试题_2028届.md](35_求职包_简历模板_面试题_2028届.md) 逐字过一遍，每个项目都能讲 5 分钟
- [ ] 所有项目链接点一遍：GitHub、报告、蜜罐，必须打得开
- [ ] 把 [工控安全面试专题20题.md](30_工控安全面试专题20题.md) + [等保测评要点速记.md](28_等保测评要点速记.md) 各背一遍
- [ ] 每天刷 2 题通用面试题，录音回听
- [ ] 准备 1 个"最近关注的漏洞新闻"，练到能讲 1 分钟

## 第 2 周：模拟面试 + 开投（8.17–8.23）

- [ ] 找同学/老师/镜子里的人，完整走 3 场模拟面试（自我介绍 2 分钟 + 技术 15 分钟 + 反问 2 分钟）
- [ ] 自我介绍背到不看稿：专业 → 为什么做安全 → 我有什么（项目/证书/实习）
- [ ] **开始投递**：目标公司清单（等保测评机构、安服乙方、集成商、工控厂商）每家投一遍，每天 5–10 家
- [ ] 建一个表格：公司 / 岗位 / 投递日期 / 进展 / 面试题记录

## 第 3 周：边面边补（8.24–8.30）

- [ ] 每场面试当天写复盘（模板在求职包里），不会的题当晚补
- [ ] 面试被问倒两次以上的知识点，写进打卡重点练
- [ ] 简历按面试反馈微调（同一个问题被问 3 次，说明你简历里那句话没写清）
- [ ] 跟进投了没回音的，礼貌问一次

## 第 4 周：面试高峰（9.1–9.9）

- [ ] 面试集中期：前一天备好（公司业务一句话、岗位 JD 重读、路线怎么去、证件材料）
- [ ] 收到 offer 按下面的清单判断，别急着签
- [ ] 没 offer 也不停投——秋招持续到 11 月，春招还有一轮

## 面试前 1 小时检查清单

- [ ] 简历 PDF 发到手机 + 打印 2 份
- [ ] 身份证、学生证、证书原件
- [ ] 项目链接在手机浏览器打开好
- [ ] 提前到 20 分钟；线上面试提前测好摄像头/麦克风/网络
- [ ] 问清对方：岗位做什么、出差频率、试用期、薪资构成

## Offer 判断清单（别只看月薪）

- [ ] 薪资构成：底薪多少、绩效占比、年终几个月、有没有画饼
- [ ] 五险一金：缴不缴、按什么基数（很多公司按最低基数缴）
- [ ] 试用期多长、打折多少（《劳动合同法》：试用期最长 6 个月、不低于 80%）
- [ ] 出差频率和补贴（安全服务/等保测评出差是常态，问清楚）
- [ ] 培训、违约金条款（**签违约金要三思**）
- [ ] 入职时间、三方协议流程（和学校就业处确认）

## 红线（出现任何一条，扭头就走）

- 交钱入职、培训贷、扣押证件原件
- "先实习再转正、转正前没合同"
- 口头承诺不写进合同
- 让你做未授权的攻击/测试
