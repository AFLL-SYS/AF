# 十年规划（2026 → 2036）—— 合在一起的总图

> 把前面所有决定合成一份：方向（OT 工控安全）、条件（专科 2028 届 / 直接就业 / 英语薄弱 / 32G+1T）、资源（35 份资料）、截止线（2027.9 秋招）。
> 这份是"屋顶"，35 份资料是"砖"。每 2 年复盘一次，目标可换，三件事不能丢：**动手、作品、底线**。

## 0. 起点（2026-10-06 的你）

专科 2028 届 · 机械制造及自动化 · 决定直接就业 · 方向 OT 工控安全（IT 安全打底 + OT 差异化）。
资产：一台 32G+1T 电脑、78 目录 35 份资料、每天可投入 2–2.5 小时。

## 2. 阶段详解

### 阶段 0（2026–2028）：求学与入行

- 2026.10–2027.06：执行 35 份资料（6 周主线 → 检查点 11.15 / 2027.01 / 2027.06）
- 2027.01–02：**寒假实习（全年最关键的一步）**
- 2027.04–06：证书（软考中级信息安全工程师）+ 一场 CTF + HW 蓝队报名
- 2027.07–09：秋招主投；2028.03–06：春招补录 + 毕业
- **检查点（2028.06）**：拿到 offer，毕业即入职
- **Plan B**：没进安全行业 → 用专业走工控/自动化技术支持岗，入行后 3 年内曲线转安全

### 阶段 1（2028–2030）：站稳（0–2 年经验）

- 第一年：把手上活干漂亮（安服/测评/实施），出差攒现场经验，每个项目写复盘
- 第二年：独立负责小项目；考第二个证书（CISP 或软考高级起步）；**主动申请工控类项目**（测评机构的工控系统测评、厂商的工控安全实施）——这是转 OT 的关键动作
- 学历补强：报在职本科（成人/自考，计算机或自动化方向，2031 年前拿证），为跳槽清障
- 英语：技术阅读过关（能啃 IEC 62443 摘要）
- **检查点（2030）**：能独立带项目，手上有 3–5 个工控相关项目经历
- 收入参考：应届 4–8k → 两年后 8–15k（随城市行情浮动，不当承诺看）

### 阶段 2（2030–2033）：专精 OT 安全（3–5 年）

- 技能：工控协议吃深（S7 / OPC UA / DNP3 到协议级）、授权工控渗透、IEC 62443 与等保工控扩展的深度解读、从仿真靶场走向真实产线
- 证书/职称：软考高级 / CISP / IEC 62443 相关认证
- 位置：跳向甲方（电力/石化/轨交安全部门）、工控安全厂商（研发/售前专家）、或大测评机构的工控方向负责人
- 输出：开始写文章、做内部分享，建立行业小圈子
- **检查点（2033）**：圈内说到"工控安全"能想起你；收入进入安全行业前 30%

### 阶段 3（2033–2036）：立身（6–10 年）

两条路选一条：
- **路 A 管理者**：安全团队负责人/总监——补管理（带人、预算、汇报）
- **路 B 专家**：工控安全研究员/架构师/独立顾问——补深度与输出（标准参与、大会演讲、白皮书）

共同点：有一件**代表作**（被引用的报告 / 标准 / 大会演讲 / 一套方法论）。
**检查点（2036）**：行业里有你的名字，工作选择权在自己手里。

## 3. 三条副线（十年维度的保命线）

1. **健康**：久坐行业，每周 3 次运动、每年体检。你下载的《高性价比人生指南》第 1、2 节讲的就是这个
2. **财务**：前 3 年攒够 6–12 个月生活费做安全垫；社保公积金从第一份工作开始别断；不碰高杠杆和"内部消息"
3. **英语**：阶段 1 过"读"，阶段 2 过"写"，阶段 3 能"说"（国际会议、标准组）

## 4. 复盘机制（十年计划不是死的）

- 每 2 年大复盘：2028 / 2030 / 2032 / 2034（和检查点重合）
- 每次只答三个问题：**我在哪（和计划差多少）/ 行业往哪走（OT 安全还热吗）/ 下一步砍什么、加什么**
- 规则：阶段目标可以换，三件事不能丢——**动手、作品、底线**

## 6. 三个"如果"（Plan B 提前埋好）

1. **如果安全入行失败** → 工控/自动化技术支持岗，专业兜底，3 年内曲线转安全
2. **如果学历成硬瓶颈** → 阶段 1 的在职本科已排好（2028 报名、2031 前拿证）
3. **如果 OT 安全行业遇冷** → 网络/Web/应急这些 IT 安全通用技能永远是退路，阶段 0 学的东西不会白学
