# 渗透测试全流程手册（一张地图串起你所有文件）

> 标准渗透测试的 8 个阶段。每个阶段：目的 → 工具 → 输出物。面试问"讲讲渗透流程"就按这个背。

## 阶段一：明确范围与授权（没有这步，后面全是犯罪）

- 拿到**书面授权**，划清：哪些 IP/域名能测、什么时间能测、什么动作禁止
- 输出物：授权书/测试范围表
- **你的一切练习，授权范围 = 自己的靶场**

## 阶段二：信息收集（侦察）

- 被动（不碰目标）：whois、子域名枚举、搜索引擎、GitHub 泄露、Shodan/ZoomEye 公开信息
- 主动（开始接触）：`nmap -sn` 找存活 → `nmap -sV` 服务版本（见 [Nmap与端口扫描手册.md](17_Nmap与端口扫描手册.md)）
- 输出物：资产清单、端口服务表、攻击面清单

## 阶段三：威胁建模与漏洞发现

- 版本号 → 已知漏洞（searchsploit / CVE 库）
- Web 手工测（Burp）+ 目录扫描（dirsearch）+ 注入测试（见 Web 主线各手册）
- 输出物：疑似漏洞清单（按可能性排序）

## 阶段四：漏洞利用（拿权限）

- 工具：sqlmap、msfconsole、手工 payload（见 [SQL注入进阶手册.md](15_SQL注入进阶手册.md)、[安全工具命令速查合集.md](18_安全工具命令速查合集.md)）
- 输出物：一个 shell / 一段证明截图

## 阶段五：后渗透（进门之后）

- 信息收集（id/网卡/邻居）→ 提权 → 横向移动（见 [内网基础手册.md](26_内网基础手册.md)）
- 输出物：权限、内网拓扑、拿到的凭证清单

## 阶段六：权限维持与清理（概念）

- 维持：后门、计划任务（只在靶场理解概念）
- 清理：删日志痕迹（理解"攻击者会做什么"，防守时才知道去哪查）

## 阶段七：报告（交付物）

- 结构、漏洞条目、定级、整改建议（见 [渗透测试报告写作模板.md](20_渗透测试报告写作模板.md)）
- **报告是渗透测试的产品**，前面六步的价值都体现在报告里

## 阶段八：复测与整改验证

- 客户修复后，重测一遍确认修好 → 出具复测结论
