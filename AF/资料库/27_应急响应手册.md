# 应急响应手册（乙方安服最常见的活儿）

## 0. 是什么

出事后第一时间"止血 → 排查 → 恢复 → 溯源 → 写报告"。面试官爱问这个，因为安服新人入职第一件事就是跟着做应急。

## 1. 标准处置流程（必背）

**准备 → 检测确认 → 抑制（隔离/断网）→ 根除（删马/修洞/改密码）→ 恢复 → 复盘报告**

关键原则：**先取证后处置**——上来就删东西会毁掉溯源证据。不确定时先问带教。

## 2. Linux 主机应急必查清单（按顺序敲）

```bash
who; w; last -20                    # 谁在登录、最近登录记录
awk -F: '$3==0 {print $1}' /etc/passwd   # 找 uid=0 的账户（多出来的就是后门账户）
history; cat ~/.bash_history        # 攻击者跑过什么
crontab -l; ls /etc/cron*           # 计划任务（挖矿/维持访问最爱藏这）
systemctl list-unit-files --state=enabled | grep -v vendor   # 开机自启
ps aux --sort=-%cpu | head -20      # 谁在吃 CPU（挖矿特征）
ss -antp                            # 网络连接：找异常外联 IP
find / -mtime -3 -type f 2>/dev/null | grep -vE '^/proc|^/sys'  # 近 3 天新增文件
tail -100 /var/log/auth.log         # 登录日志（爆破/成功登录都在）
```

再针对性查 webshell：
- 常见藏身处：网站 uploads 目录、tmp、图片目录
- 文件特征：`eval(`、`base64_decode(`、`assert(`、`shell_exec`
- 时间特征：网站文件里"最近被改动"的那个
- 工具：D盾、河马 webshell 查杀（免费）扫一遍

## 3. Windows 主机应急必查清单

```bat
netstat -ano | findstr ESTABLISHED   # 网络连接 + PID
tasklist | findstr PID               # 连接是谁的进程
msconfig                             # 启动项
schtasks /query                      # 计划任务
reg query HKCU\Software\Microsoft\Windows\CurrentVersion\Run  # 注册表自启
```
事件查看器：安全日志看 4624（成功登录）/ 4625（失败登录）追踪爆破。

## 4. 三种常见场景怎么答

| 场景 | 处置要点 |
|---|---|
| **勒索病毒** | 先断网 → 绝不付钱 → 保留现场取证 → 找备份恢复 → 查入口（RDP 弱口令最常见） |
| **挖矿木马** | CPU 拉满 → 找到进程和它的父进程 → 杀掉 + 删计划任务 + 删自启 → 改密码 |
| **webshell** | 先隔离（改网站只读/下线）→ 查杀工具扫 → 找上传漏洞入口 → 修复漏洞 + 删马 |

## 5. 应急报告模板（写完发带教）

```
1. 事件概述：什么时间、谁发现、什么现象、影响范围
2. 时间线：xx:xx 出现异常 → xx:xx 确认 → xx:xx 处置
3. 处置过程：每一步做了什么、为什么
4. 根因分析：怎么进来的（弱口令/漏洞/钓鱼）
5. 整改建议：改密码、打补丁、加监控、备份策略
```

## 6. 面试怎么答"懂应急响应吗"

标准答法：**"懂流程。准备→确认→抑制→根除→恢复→复盘，Linux 上会查登录日志、计划任务、异常进程和外联，Windows 上会看事件日志和启动项。原则是先取证后处置。"** 能说出"先取证后处置"，你就超过了 80% 的应届生。
