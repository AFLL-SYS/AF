# CTF 入门 5 题（做完就算"打过 CTF"）

> 平台：BUUCTF（buuoj.cn）Web 分类，注册即打。每题 30 分钟，卡住查 WriteUp，看懂后自己再复现一遍。
> 只做平台自己的题目，不碰任何真实系统。

## 第 1 题：view_source

- 目标：页面提示"flag 就在源代码里"
- 思路：按 F12 看源码，或直接看页面源代码
- 知识点：**信息收集的第一课——前端藏不住秘密**
- 命令：`Ctrl+U` 或 F12 → Elements

## 第 2 题：robots

- 目标：网站根目录的 robots.txt 里指了个目录
- 思路：访问 `/robots.txt` → 看它 Disallow 了哪个路径 → 访问那个路径
- 知识点：robots.txt 是给爬虫看的"哪里别去"，反过来就是"哪里藏了东西"

## 第 3 题：备份文件

- 目标：网站源码没删干净，留了 `index.php.bak` 或 `www.zip`
- 思路：试常见备份名：`.bak`、`.swp`、`www.zip`、`.tar.gz`、`.git`
- 知识点：**部署习惯漏洞**——拿到备份 = 拿到源码，审计源码找 flag
- 小工具：`dirsearch -u 目标 -e bak,zip`（Kali 里 pip 装）

## 第 4 题：Cookie 欺骗

- 目标：Cookie 里有个 `admin=0`，改成 1 就成管理员
- 思路：F12 → Application → Cookies → 把值改了 → 刷新
- 知识点：**客户端的数据永远不可信**，权限判断必须在服务端做
- 变体：`user=guest` 改 `user=admin`、JWT 里的 role 字段

## 第 5 题：简单 SQL 注入

- 目标：登录框/参数有注入点
- 思路：`'` 看报错 → `' or 1=1#` 试万能密码 → `' union select 1,2,3-- ` 找显示位
- 知识点：就是你 [SQL注入进阶手册.md](15_SQL注入进阶手册.md) 里那套，考场版
- 工具：手注不行再上 sqlmap（平台允许的前提下）

## 打完之后（比做题更重要）

1. 每题写 3 行：考点 / 我卡在哪 / 下次一眼就能看出的特征
2. 记录到打卡，简历里写"BUUCTF Web 方向 5 题"（以后攒到 50 题就更漂亮）
3. 每周固定刷 2 题，周日复盘

**入门题做不出来是正常的，80% 的人前 5 题都要查 WriteUp。** 区别在于：查完能不能自己复现。
