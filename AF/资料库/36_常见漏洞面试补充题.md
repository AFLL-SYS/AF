# 常见漏洞面试补充题（答案要点版）

> 配合 [求职包_简历模板_面试题_2028届.md](35_求职包_简历模板_面试题_2028届.md) 使用。每周末刷 5 题。

1. **SSRF 是什么？有什么危害？**
服务端替攻击者发起请求。危害：探测内网端口、读云元数据（169.254.169.254）、打内网服务。防御：URL 白名单、禁内网 IP、禁重定向。

2. **XXE 是什么？**
XML 解析器处理了外部实体。可读文件、SSRF、DoS。防御：禁用外部实体（DTD）。

3. **反序列化漏洞原理？**
把数据还原成对象时执行了攻击者构造的逻辑（Java/PHP 高发）。防御：白名单类、不信任外部输入、更新组件。

4. **越权是什么？分几类？**
水平越权（A 看到 B 的同级数据）、垂直越权（普通用户干管理员的事）。防御：服务端每次校验身份与资源归属。

5. **逻辑漏洞常见有哪些？**
支付金额篡改、验证码绕过、注册参数污染、优惠券叠加、密码重置不验证。特点：扫描器扫不出，只能人脑测。

6. **未授权访问常见哪些服务？**
Redis（6379）、MongoDB（27017）、Memcached、Elasticsearch、Docker API。防御：绑内网、加认证、防火墙。

7. **任意文件读取/下载怎么防？**
路径参数白名单、禁止 `../`、限定根目录。

8. **目录遍历和文件包含有什么区别？**
目录遍历：读文件内容（`../../etc/passwd`）；文件包含：把文件当代码执行（`include $_GET['file']`）。

9. **一句话木马是什么？**
`<?php eval($_POST['x']); ?>` 这类极短的后门。检测：文件内容特征、流量特征、上传目录监控。

10. **免杀是什么概念？**
让木马绕过杀软/EDD 检测（改特征、加密、混淆）。面试说概念即可，别现场演示。

11. **中间件常见漏洞举例？**
Weblogic 反序列化、Tomcat 管理后台弱口令/部署 war、Struts2 命令执行（S2-045）。防御：升级、删管理后台、改默认配置。

12. **WAF 绕过有哪几类思路？**
编码变形（大小写/双写/URL 编码）、注释符替换、分块传输、协议层差异。别展开讲细节，说"思路是让特征匹配失效"。

13. **供应链攻击是什么？**
通过第三方组件/软件/供应商打进目标（如投毒开源包）。防御：资产清单、来源校验、最小依赖。

14. **云安全常考点？**
对象存储桶权限错误（公开读）、SSRF 读元数据、IAM 权限过大。防御：最小权限、桶私有、日志审计。

15. **JWT 是什么？安全点在哪？**
JSON Web Token，三段式（header.payload.signature）。坑：`alg=none`、弱密钥、泄露。防御：强制算法、强密钥、短有效期。

16. **短信轰炸/验证码绕过怎么防？**
频率限制（IP+手机号）、图形验证码、服务端校验。

17. **撞库和拖库有什么区别？**
拖库：从目标网站偷出账号库；撞库：拿别处的库去目标网站试（防：验证码、风控、强制改密）。

18. **蜜罐在防守里的作用？**
引流、拖延、抓攻击者行为、溯源。面试会问 Conpot（工控蜜罐）——你有。

19. **零信任是什么？**
默认不信任任何内外部流量，每次都验证（设备+身份+权限），最小化授权。

20. **攻防演练里红队和蓝队分别干嘛？**
红队模拟真实攻击找突破；蓝队防守、监测、应急、溯源。你去蓝队（见 [护网HW经验速成.md](34_护网HW经验速成.md)）。
