# 英语最小集：300 个技术词（每天 15 分钟）

**用法**：每天 10 个，遮住中文考自己；不会的画圈，第二天先复习圈的。30 天过一遍，3 个月过 3 遍 = 记牢。
**规则**：只记"技术场景里的意思"，不背词典义。遇到新词按同样格式追加在末尾。
**目标**：看懂报错、工具文档、CVE 摘要——不是"学英语"，是"攒技术词"。

## 一、网络基础（50）

1. IP address — IP 地址（每台设备的门牌号）
2. subnet mask — 子网掩码（区分网络号和主机号）
3. gateway — 网关（出门的路口，默认路由）
4. DNS — 域名系统（把名字翻译成 IP）
5. DHCP — 动态主机配置协议（自动发 IP）
6. ARP — 地址解析协议（IP 找 MAC）
7. MAC address — 物理地址（网卡出厂号）
8. port — 端口（一个 IP 上的不同服务窗口）
9. protocol — 协议（双方约定的说话规则）
10. TCP — 传输控制协议（可靠，三次握手）
11. UDP — 用户数据报协议（快，不保证到）
12. HTTP — 超文本传输协议（网页明文传输）
13. HTTPS — 加了 TLS 的 HTTP（加密）
14. FTP — 文件传输协议
15. SSH — 安全外壳（远程登录 Linux）
16. SMTP — 简单邮件传输协议
17. ICMP — 互联网控制报文协议（ping 用的）
18. packet — 数据包
19. frame — 帧（二层的数据包）
20. header — 头部（包的开头信息）
21. payload — 载荷（包里的实际数据）
22. checksum — 校验和（检查数据有没有坏）
23. handshake — 握手（建立连接的过程）
24. socket — 套接字（IP+端口 的通信端点）
25. endpoint — 端点
26. router — 路由器
27. switch — 交换机
28. firewall — 防火墙
29. NAT — 网络地址转换（内网共用一个公网 IP）
30. VPN — 虚拟专用网络（加密隧道）
31. proxy — 代理（替你去访问的中间人）
32. VLAN — 虚拟局域网（逻辑隔离）
33. broadcast — 广播
34. multicast — 组播
35. unicast — 单播
36. latency — 延迟
37. bandwidth — 带宽
38. throughput — 吞吐量
39. sniffing — 嗅探（抓包偷听）
40. spoofing — 欺骗（冒充别人）
41. flooding — 泛洪（大量灌包）
42. DoS — 拒绝服务（把目标打瘫）
43. DDoS — 分布式拒绝服务（一群机器一起打）
44. MITM — 中间人攻击
45. tunneling — 隧道（把一种包封装进另一种）
46. encapsulation — 封装
47. ethernet — 以太网
48. wireless — 无线
49. upstream — 上游 / 上行
50. downstream — 下游 / 下行

55. enumeration — 枚举（列目录、找用户）
56. footprinting — 踩点

58. persistence — 持久化（站稳脚跟）

60. pentest — 渗透测试（拿到授权后的"体检"）
61. phishing — 钓鱼（邮件/网站骗人）
