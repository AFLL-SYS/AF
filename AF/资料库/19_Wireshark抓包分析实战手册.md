# Wireshark 抓包分析实战手册（五个实验，做完会分析）

## 0. 三个用途

1. 学协议：看不见就听不懂，抓下来看真的
2. 验证攻击：你发的 payload 在包里长什么样
3. 应急取证：被黑之后，流量是证据

## 1. 界面三区 + 过滤器

三区：包列表（上）/ 包详情（中，能展开看每一层）/ 原始字节（下）。
常用过滤器（详见 [网络协议速查表.md](09_网络协议速查表.md)）：`ip.addr==目标`、`tcp.port==80`、`http`、`tcp.flags.syn==1`、`mbtcp`、`s7comm`。

## 2. 实验一：看 TCP 三次握手

1. 开抓包 → 浏览器访问任意网站 → 停
2. 过滤 `tcp` → 找到 `[SYN]`、`[SYN, ACK]`、`[ACK]` 三个连续包
3. 展开中间包看 Flags 位，记住顺序
**验收**：能指着三个包说出"这是第几次握手"。

## 3. 实验二：看 HTTP 明文 vs HTTPS

1. 访问 `http://example.com` → 过滤 `http` → 找到请求，右键 **Follow → TCP Stream**
2. 看到完整明文（请求头 + 响应） = 为什么明文传输危险
3. 再访问一个 https 网站 → 同过滤 → **只有乱码** = 为什么需要证书
**验收**：能讲"HTTP 裸奔、HTTPS 加密"的包级证据。

## 4. 实验三：看 Modbus TCP（你的工控实验）

1. 起 OpenPLC，Python 跑读写脚本的同时抓包（配合 [工控实验手册_OpenPLC与Modbus.md](25_工控实验手册_OpenPLC与Modbus.md)）
2. 过滤 `mbtcp` 或 `tcp.port==502`
3. 展开每个包找 **Function Code**：读线圈=1、写线圈=5、读保持寄存器=3、写寄存器=6/16
4. **验证"无认证无加密"**：包里的功能码、地址、数据全是明文，一眼看懂
**验收**：能对着一个包说出"它在读什么、地址多少"——这是工控安全面试的实物级证据。

## 5. 实验四：看 ARP 问答

1. 过滤 `arp`
2. 正常现象：`Who has 192.168.x.x? Tell ...` + 一条应答
3. **攻击特征**：短时间内大量"免费 ARP"（同一 MAC 冒充网关 IP 反复广播）＝ 有人在做 ARP 欺骗
**验收**：能区分"正常问答"和"欺骗广播"。

## 6. 实验五：看爆破流量

1. 用 hydra 爆自己的靶机（[安全工具命令速查合集.md](18_安全工具命令速查合集.md)）
2. 同时抓包 → 过滤 `tcp.port==22` 或 80
3. 特征：同一源 IP → 大量连接/登录请求 → 全部失败
**验收**：能从流量侧描述"爆破长什么样"——蓝队研判就是这个思路（见 [护网HW经验速成.md](34_护网HW经验速成.md)）。

## 7. 三个提速技巧

- 右键 → **Follow → TCP Stream**：把一次会话的所有包连起来看（最常用）
- **Statistics → Conversations**：看谁跟谁聊得最多（找异常外联）
- **File → Export Objects → HTTP**：把抓到的文件直接导出来

## 8. 常见坑

- 抓不到 HTTPS 明文：正常，加密的。除非装好你自己的证书做中间人
- 抓不到别人的包：你没在混杂模式/不在同一广播域——只抓自己的流量就够了
- 包太多眼花：先 `Statistics → Protocol Hierarchy` 看整体，再逐步过滤
