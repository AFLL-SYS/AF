# Python 安全小项目 5 个（做完 = 简历有货）

> 每个项目 ≤200 行、只用你已学的库（requests/socket/pymodbus/matplotlib）。做完一个放一个到 GitHub。
> 全部只对本地/自己的环境使用。

## 项目 1：端口扫描器（第 3 周后）

- 做什么：输入 IP/网段，输出开放端口列表
- 核心：`socket.connect_ex()` 带超时循环，或多线程加速
- 验收：扫自己的 Kali，结果和 `nmap` 对得上
- 简历文案：*"自研 TCP 端口扫描器，支持多线程与超时控制"*

## 项目 2：子域名枚举器（第 4 周后）

- 做什么：给定主域名 + 字典，批量解析子域名并验证存活
- 核心：`requests` + 字典循环 + `try/except`；字典从网上下一个常用 top1000
- 验收：跑一个公开的练习域名，输出存活子域名列表
- 简历文案：*"编写子域名枚举工具，字典驱动 + 批量存活验证"*

## 项目 3：弱口令检查器（第 5 周后）

- 做什么：对**自己的服务**（本地 SSH/Web 登录）用字典批量试登录
- 核心：hydra 逻辑自己实现一遍（或封装 hydra），记录成功项
- 验收：对自己靶机的 SSH 弱口令跑通一次
- 简历文案：*"实现弱口令检测脚本，覆盖 SSH/Web 表单场景"*
- **红线**：只能指向自己的靶机

## 项目 4：日志分析器（第 5 周后）

- 做什么：读 Linux auth.log，统计"失败登录最多的 IP"、"爆破时间段"
- 核心：`re` 提取字段 + `collections.Counter` 统计 + 输出 Top10
- 验收：分析自己 Kali 的 auth.log，输出一张 Top10 表
- 简历文案：*"开发登录日志分析工具，自动提取爆破源 IP 与时间分布"*

## 项目 5：Modbus 采集看板（第 3 周起，你的主项目）

- 做什么：pymodbus 每秒读 OpenPLC 寄存器 → 存 SQLite/CSV → matplotlib 画趋势图
- 核心：就是 [工控实验手册_OpenPLC与Modbus.md](25_工控实验手册_OpenPLC与Modbus.md) + [Python工具脚本模板库.md](32_Python工具脚本模板库.md) 的组合
- 验收：跑 10 分钟，输出一张趋势图 + 一份数据
- 简历文案：*"搭建 OpenPLC+Modbus 仿真环境，实现数据采集、入库与可视化，输出暴露面报告"*

## 通用规则

1. 每个项目一个目录：`scanner/`、`subenum/`、`weakpass/`、`logana/`、`modbus-dash/`
2. 每个目录一个 README：干什么、怎么跑、示例输出
3. 写完 push 到 GitHub——**简历上 5 个项目，比"熟练 Python"有说服力十倍**
4. 项目 5 是主打（工控方向），花的时间应该是其他四个的总和

## 时间安排
