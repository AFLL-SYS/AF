# 实习期生存手册（寒假实习 = 整条路最关键的一步）

## 0. 先想清楚：实习的目标不是赚钱

是这三样，按优先级：
1. **一段能写进简历、能展开讲 5 分钟的经历**
2. **一份带教/公司的认可**（转正机会、内推、背调推荐人）
3. 学点真东西 + 一点点补贴

## 1. 入职前（一天搞定）

- 确认书面内容：实习协议、岗位职责、实习期、补贴多少、每周几天
- 记下带教的名字、联系方式；问清"我的第一周干什么"
- 准备三样：简历电子版、证件、一个笔记本（好记性不如烂笔头，记笔记的实习生最受欢迎）

## 2. 第一周（决定印象）

- 领任务时**复述一遍**："您的意思是让我做 A、B、C，周四前交，对吗？"——确认听懂比装懂强十倍
- 不懂就问，但先自己查 10 分钟（带教最烦两种人：不懂装懂、张嘴就问）
- 每天下班前给带教发一句话小结："今天完成了 X，卡在 Y，明天做 Z"——这 3 行话是实习生最便宜的加分项

## 3. 干活五原则

1. 交东西前**自己检查一遍**（错字、截图、格式）——别让带教给你当校对
2. 遇到"不会"说"**我去学一下**"，而不是"我不会"
3. 承诺了时间就守时；做不到提前说，别拖到 deadline 才讲
4. 别人说话时别打断；客户面前别插嘴
5. 每天写一点点复盘（带数字），实习结束就有现成的总结

## 4. 红线（踩一条就可能提前走人）

- 不碰**未授权**的系统、数据、账号
- 不把客户数据、公司资料发到自己邮箱/网盘
- 不私下接单、不拿客户联系方式接私活
- 不迟到、不玩手机、不在群里乱说话
- 不在社交平台发公司内部信息（含截图）

## 5. 实习总结怎么写（照这个结构）

```
1. 一句话：在 XX 公司安全服务部实习 X 个月，参与 XX 项目
2. 带数字：独立完成 Y 项配置核查 / 写了 Z 份报告 / 参与了 N 次现场测评
3. 学到什么：流程、工具、沟通（各一句）
4. 一个细节：某次具体问题你怎么解决的（面试时展开讲这段）
```

## 6. 怎么争取转正/内推

实习最后两周，主动找带教聊一次：
"我挺喜欢这里，也觉得自己上手了。毕业季有没有转正或推荐的机会？如果有，我需要补什么？"
——被拒绝也不亏，你知道了差距。**不问 = 一定没有。**

## 7. 一句话

**实习的第一目标，是让带教在背调时愿意为你说好话。** 这比那点补贴值钱一百倍。
