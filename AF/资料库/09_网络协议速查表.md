# 网络协议速查表（面试必问 + 抓包对照）

## 1. 分层模型（先背这个）

| OSI 七层 | TCP/IP 四层 | 设备 | 典型协议 |
|---|---|---|---|
| 应用层 | 应用层 | 防火墙/网关 | HTTP/DNS/FTP/SSH |
| 表示层 | ↑ | | |
| 会话层 | ↑ | | |
| 传输层 | 传输层 | 防火墙 | TCP/UDP |
| 网络层 | 网络层 | 路由器 | IP/ICMP/ARP |
| 数据链路层 | 网络接口层 | 交换机 | Ethernet |
| 物理层 | ↑ | 网线/集线器 | 电信号 |

面试说 TCP/IP 四层（应用/传输/网络/网络接口），别背七层全名，记住"物理层=网线，交换机=二层，路由器=三层"。

## 2. TCP 三次握手 / 四次挥手

三次握手：客户端 SYN → 服务端 SYN+ACK → 客户端 ACK（问："能听见吗？""能，你呢？""能。"）
四次挥手：FIN → ACK → FIN → ACK（双向关闭各两次）

**为什么三次**：双方都要确认"我的发、我的收"都通。两次只够一方确认。

## 5. HTTP 报文与状态码

请求结构：请求行（方法+路径+版本）→ 请求头 → 空行 → 请求体。
常考请求头：`User-Agent`（浏览器指纹）、`Cookie`（会话）、`Referer`（从哪来）、`Content-Type`（数据格式）。

| 状态码 | 含义 |
|---|---|
| 200 | 成功 |
| 301/302 | 跳转（302 常被用于登录后重定向） |
| 400 | 请求有错 |
| 401 | 未认证 |
| 403 | 没权限 |
| 404 | 不存在（扫描时大量 404 = 有人在扫目录） |
| 500 | 服务器报错（注入报错常在这暴露） |
| 502 | 网关错误 |

## 6. DNS 解析过程（简述版）

浏览器缓存 → 系统 hosts → 本地 DNS 服务器 → 递归查根域/顶级域/权威域 → 返回 IP 并缓存。

## 7. ARP 一句话

同网段通信靠 MAC，ARP 就是"谁知道 192.168.1.1 的 MAC 是什么"的广播问答。**没有验证机制 → 谁都能冒充网关回答（ARP 欺骗）**。

## 8. 面试标准答法：TCP 和 UDP 区别

"TCP 面向连接、可靠（三次握手、重传、有序），适合网页/文件；UDP 无连接、快但可能丢包，适合直播/视频通话/DNS。攻击者角度：UDP 更容易伪造源地址，TCP 有握手可做 SYN Flood。"

## 9. Wireshark 过滤器速查

| 过滤器 | 抓什么 |
|---|---|
| `ip.addr==192.168.1.10` | 某 IP 的全部流量 |
| `tcp.port==80` | 某端口的流量 |
| `http` / `dns` / `icmp` | 按协议 |
| `tcp.flags.syn==1` | 只看握手包 |
| `mbtcp` | Modbus TCP |
| `s7comm` | 西门子 S7 |

用法：背 5 个常用的，抓包时先 `ip.addr==靶机` 再逐步缩小。
