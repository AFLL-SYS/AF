# 第一份工作避坑手册（2028 年 6 月用）

> 应届生被坑基本都在这几件事上。签任何字之前，对着这份查一遍。

## 1. 合同（签之前逐条看）

- [ ] 职位、工作地点写清楚（"服从安排"要问清）
- [ ] 薪资构成：底薪多少、绩效怎么算、年终几个月——**只写"面议"或没数字的别签**
- [ ] 试用期：最长 6 个月（3 年以上合同）、不低于转正的 80%、**试用期也必须签合同、缴社保**
- [ ] 违约金条款：除竞业/培训服务期外，一般不得约定违约金——出现大额违约金要三思
- [ ] 合同两份，你手里必须留一份

## 2. 五险一金

- [ ] 入职当月问：公积金比例多少、按什么基数缴（**按最低基数 vs 按实际工资，差很多**）
- [ ] 试用期就开始缴——不缴是违法
- [ ] 异地办公问清社保缴在哪个城市（影响看病、公积金贷款）

## 3. 租房（去新城市的第一件事）

- [ ] 押金写进合同，拍照+视频留底（退租扯皮全靠它）
- [ ] 通勤控制在 40 分钟内——刚入行精力比房租重要
- [ ] 别押一付三还被收"中介费+服务费"双重

## 4. 档案与报到

- [ ] 毕业时档案去向：公司有资质就转公司，否则转回生源地人才市场——**档案千万别自己拿在手里**
- [ ] 报到证/毕业证/学位证拍照存档，原件不外借（办入职现场用，用完拿回）

## 5. 反套路清单（任何一条出现，扭头就走）

1. 先交钱：报名费、培训费、服装费、押金——**正规公司不会向员工收钱**
2. 培训贷："先培训后上岗，学费从工资扣"——这不是工作，是贷款
3. 扣证件："身份证/毕业证先押在公司"——违法
4. 无合同先干活："先干 3 个月看表现再签"——这 3 个月没人管你
5. 画饼："现在工资低，年底翻倍"——**合同上没写 = 没有**

## 6. 第一年最该做的三件事（比技术重要）

1. **社保不断缴**——断缴影响太多东西
2. **攒 3–6 个月生活费**——这是你敢跳槽、敢拒绝烂活的底气
3. **每周雷打不动学 3 小时**——第一年不学，第三年就后悔

## 7. 一句话

**合同上的字，比面试官说的话算数。** 拿不准的条款，拍照问学校就业处老师、问家里长辈，别自己猜。
