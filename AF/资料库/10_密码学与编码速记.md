# 密码学与编码速记（面试 + CTF 都考）

## 1. 三件事先分清（面试必考第一题）

| 类型 | 特点 | 例子 |
|---|---|---|
| **编码** | 可逆、无密钥、不是加密 | Base64、Hex、URL 编码 |
| **加密** | 要密钥、可逆 | AES（对称）、RSA（非对称） |
| **哈希** | 定长、单向不可逆 | MD5、SHA-1、SHA-256 |

标准答法："Base64 是编码不是加密，因为它没有密钥、任何人都能解开；加密必须有密钥；哈希是单向的，用于存密码和校验完整性。"

## 2. 一眼识别（看到密文先判断）

| 长相 | 是什么 |
|---|---|
| 结尾有 `=` 或 `==`，字母大小写混合 | Base64 |
| `0x` 开头或全是 0-9a-f | Hex |
| 32 位 0-9a-f | 可能是 MD5 |
| 40 位 0-9a-f | 可能是 SHA-1 |
| 64 位 0-9a-f | 可能是 SHA-256 |
| `%2f%3a` 这种 | URL 编码 |

## 3. 常用命令（Kali 一行搞定）

```bash
echo -n "hello" | base64            # 编码
echo "aGVsbG8=" | base64 -d         # 解码
echo -n "hello" | md5sum            # MD5
echo -n "hello" | sha256sum         # SHA-256
echo -n "hello" | xxd -p            # 转 hex
```

## 4. 对称 vs 非对称（面试必考）

- **对称**（AES/DES）：一把钥匙，加密解密都用它。快，但"钥匙怎么安全地给对方"是难题。
- **非对称**（RSA）：公私钥一对。公钥加密、私钥解密；反过来用就是**签名**。慢，所以 HTTPS 是"用非对称交换密钥 + 用对称加密数据"。

## 5. RSA 在 CTF 里怎么考（入门级）

- **考点一**：N 太小 → 用 yafu/factordb 分解出 p、q → 按公式算出私钥
- **考点二**：公钥 e 太小（如 e=3）且密文不够大 → 直接开方
- 入门题都有现成工具和 WriteUp，看懂公式 `m = c^d mod n` 就行

## 6. 古典密码（CTF 常客）

- 凯撒：字母统一平移（用工具暴力试 26 种）
- 栅栏：把明文排成 N 列再横着读
- 摩斯：`-` 和 `.` 的点划组合
- 猪圈密码、培根密码：图形/AB 组合，见到就搜图对照

## 7. 密码破解（拿到哈希怎么办）

```bash
echo '5f4dcc3b5aa765d61d8327deb882cf99' > h.txt
john --wordlist=/usr/share/wordlists/rockyou.txt h.txt
john --show h.txt
```
秒出 = 弱口令（rockyou 里有）；出不来 = 加盐或强密码，换思路。

## 8. 面试加分句

"密码学我只学到'用得对'：存密码用哈希加盐（bcrypt），传数据用 TLS，判断密文类型会看长相。深度算法我不装懂。"
——这句比硬背 RSA 公式更讨面试官喜欢。
