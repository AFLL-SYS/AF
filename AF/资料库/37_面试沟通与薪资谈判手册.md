# 面试沟通与薪资谈判手册（HR 关的答案都在这）

## 1. HR 高频 15 题（每题一句话思路）

1. **自我介绍**（必考）：专业 → 为什么做安全 → 我有什么（项目/证书/实习），2 分钟
2. **为什么选我们公司**：提前查公司业务一句话 + 结合你的工控方向
3. **你的缺点**：说真缺点 + 正在怎么改（"我英语底子差，正在每天 15 分钟补技术词"）
4. **为什么机械专业转安全**：工控安全需要懂设备和现场的人，我两边都沾——见 [工控安全面试专题20题.md](30_工控安全面试专题20题.md) 第 20 题
5. **期望薪资**：见下面第 2 节，别先报数
6. **到岗时间**：应届生答"毕业即到岗；实习随时"
7. **职业规划**：一年上手安服/测评 → 三年独立负责项目 → 往工控安全专
8. **学历（专科）**：不回避："学历是我现在补不上的，但动手能力和证书我能给证据"
9. **家住哪/接受出差吗**：如实；出差说清"接受、清楚这行是常态"
10. **手上还有其他 offer 吗**：诚实说"在面 X 家，但更想来这里因为 Y"
11. **能接受加班吗**：答"接受项目需要的加班，会优先提升效率"，别反提问
12. **说说实习经历**：STAR 讲，提前练熟
13. **你的优势**：懂工控 + 会动手 + 有作品 + 有打卡习惯（自律证据）
14. **有什么想问我们的**：团队分工 / 出差频率 / 新人培养 / 转正标准
15. **最后还有什么补充**：30 秒把最想被记住的一点再说一遍（比如"我能独立写报告"）

## 2. 期望薪资怎么答（应届生公式）

**"我对薪资的理解是：先看成长空间，其次符合市场。我了解过这个岗位应届的大致范围，具体数字拿到 offer 时再谈，我更关心进来之后三年能到什么位置。"**

要点：
- HR 问薪资=摸底，谁先报数谁被动
- 被追问就报**区间**（查过行情再报）："X–Y，看岗位职责和五险一金"
- 永远问清：底薪、绩效、年终、五险一金基数、出差补贴——**月薪 6000 全额缴社保 ≠ 月薪 8000 按最低基数**

## 3. 投递话术（BOSS/招聘软件开场白）

```
您好，我是 2028 届机械制造及自动化专业学生，方向是工控安全。
自学了 Web 安全（DVWA 全关卡）和工控协议（Modbus/OpenPLC），
有 GitHub 项目和个人练习报告，可立即到岗实习。简历如下，方便聊两句吗？
```

跟进（3 天没回）："您好，简历发过 X 天没动静，想确认下这个岗位还在招吗？"
被拒："谢谢反馈。能请教一句我哪方面最需要补吗？"（**被拒也要问，白捡的信息**）

## 4. 邮件模板（投简历用）

```
主题：应聘【岗位名称】- 张三 - 2028届 - 可立即实习
正文：
您好，我是 XX 职业技术学院机械制造及自动化专业 2028 届学生。
我的方向和贵司【岗位/业务】匹配：______（一句话）。
三个事实：① DVWA 四类漏洞全通关并有迷你报告；② 用 OpenPLC+Modbus
搭过工控仿真并输出暴露面报告；③ 证书/比赛：______。
简历见附件，项目链接：______。盼复，谢谢！
```

## 5. 谈 offer 时的铁规矩

1. **一切以书面为准**——口头承诺 = 没有承诺
2. 确认：薪资构成、五险一金基数、试用期与打折、出差补贴、违约金条款
3. 违约金条款要三思——应届生被坑大多在这一条
4. 签三方前跟学校就业处核对流程

## 6. 红线（出现就走）

交钱入职 / 培训贷 / 扣押证件原件 / 无合同先干活 / 让你做未授权的攻击测试。
